2. Maze Solver Bot (Recursion + Backtracking)
Function solveMaze(maze, x, y, visited):
    if (x,y) is destination → return true

    if (x,y) is valid and not visited:
        mark visited[x][y] = true

        if solveMaze(right cell) → return true
        if solveMaze(down cell) → return true
        if solveMaze(left cell) → return true
        if solveMaze(up cell) → return true

        unmark visited[x][y]  // backtrack

    return false
